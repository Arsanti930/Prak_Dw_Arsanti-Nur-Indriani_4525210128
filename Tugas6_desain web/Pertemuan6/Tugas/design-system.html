06 · Cards

Card memakai surface putih, border netral, radius 14 piksel, padding seragam, dan shadow halus.

Ringkasan akademik

Contoh komponen card untuk menampung informasi yang saling berkaitan. Jarak antar elemen menggunakan token spacing.

Token CSS tersimpan pada bagian :root dalam file css/style.css agar dapat dipakai ulang.
