## Deskripsi

Proyek ini adalah latihan **Desain Web** berupa halaman **Profil Pribadi** sederhana menggunakan HTML. Fokus latihan ini adalah penggunaan **hyperlink**, **gambar**, **daftar**, dan **struktur semantik** HTML.

## Fitur / Isi Halaman

| Bagian            | Keterangan                                                        |
| ----------------- | ----------------------------------------------------------------- |
| **Header**        | Judul "Profil Pribadi" dan foto diri                              |
| **Biodata Singkat** | Nama, status, jurusan, deskripsi, dan tautan Instagram          |
| **Hobi Saya**     | Daftar hobi menggunakan *unordered list*                          |

## Tag HTML yang Dipelajari

- `<header>` dan `<section>` : struktur semantik halaman
- `<h1>`, `<h2>` : judul dan subjudul
- `<img>` : menampilkan foto (atribut `src`, `alt`, `width`)
- `<a href="..." target="_blank">` : hyperlink yang terbuka di tab baru
- `<ul>` dan `<li>` : daftar tidak berurutan
- `<strong>`, `<p>`, `<hr>` : teks tebal, paragraf, dan garis pemisah
- Komentar HTML `<!-- ... -->`

## Cara Menjalankan

1. Clone atau unduh repositori ini.
2. Buka folder proyek menggunakan **Visual Studio Code**.
3. Buka `latihan_hyperlink.html` di browser (klik dua kali, atau gunakan ekstensi *Live Server*).
