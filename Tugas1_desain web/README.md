## Deskripsi

Repositori ini berisi tugas **Praktikum 1 Desain Web A**, yaitu membuat halaman **Profil Mahasiswa** sederhana menggunakan HTML dasar.

Halaman ini bertujuan untuk melatih penggunaan tag-tag dasar HTML, antara lain:

- Heading (`<h1>`, `<h2>`, `<h3>`)
- Paragraf (`<p>`) dan baris baru (`<br />`)
- Pemformatan teks (`<strong>`, `<em>`, `<b>`, `<u>`)
- Karakter khusus / HTML entities (`&lt;`, `&gt;`, `&copy;`)

## Cara Menjalankan

1. Clone atau unduh repositori ini.
2. Buka folder proyek menggunakan **Visual Studio Code** (atau buka berkas `Tugas1_desain_web.code-workspace`).
3. Buka berkas `latihan_1_.html` di browser (klik dua kali, atau gunakan ekstensi *Live Server*).
