REN OMAKASE — Landing Page & Reservation System

Selamat datang di repositori web REN OMAKASE, sebuah aplikasi web responsif dan elegan untuk landing page restoran otentik Jepang serta sistem pendaftaran reservasi meja secara online.

Deskripsi Proyek

Proyek ini dibangun untuk memberikan pengalaman pengguna (user experience) bertema luxury & authentic Japanese dining. Situs web ini mencakup informasi mengenai filosofi restoran, statistik layanan, pilihan set menu Omakase, fasilitas unggulan, lokasi, serta formulir reservasi interaktif berbasis web.

 Fitur Utama

Header & Navigation Bar Sticky: Navigasi cepat menuju setiap bagian halaman.

Hero Banner: Tampilan gambar latar visual restoran dengan CTA (Call to Action).

Statistik & Highlight: Penjelasan singkat mengenai konsep Omakase dan kapasitas restoran.

Kartu Layanan/Paket (Cards Grid): Menampilkan berbagai pilihan set menu santap (Matsu Experience, Kiwa Signature, VIP Full Omakase) beserta rincian harga.

Fasilitas Restoran: Informasi fasilitas seperti Hinoki Wood Counter, Sake Cellar, dan Valet Parking.

Formulir Reservasi Interactive:

Validasi tanggal otomatis (tidak dapat memilih tanggal lampau).

Tampilan konfirmasi dinamis tanpa reload halaman setelah submit.

Fitur untuk melakukan reservasi ulang.

Desain Responsif: Optimal saat diakses dari perangkat seluler (Mobile) maupun desktop.

 Design System & Panduan Styling (style.css)

Sistem desain yang diterapkan mengacu pada standar komponen web modern:
Color Palette:

Primary Color: Deep Crimson / Dark Red (#8B0000)

Secondary Accent: Warm Gold (#D4AF37)

Neutral Dark: Dark Charcoal (#1A1A1A)

Neutral Light: Warm Off-White (#F9F8F6)

Typography: Google Font Plus Jakarta Sans.

Layout & Spacing: Grid System 3 Kolom pada layar besar, serta Flexbox untuk bagian Navigasi dan Footer.

 Cara Menjalankan Proyek

Clone / Unduh Repositori
Unduh semua file dalam repositori ini ke dalam satu folder lokal.

Jalankan Berkas
Buka file index.html menggunakan peramban web (browser) modern seperti Google Chrome, Mozilla Firefox, Microsoft Edge, atau Safari.

Tanpa Dependensi Tambahan
Proyek ini murni menggunakan HTML5, CSS3, dan Plain JavaScript, sehingga tidak memerlukan instalasi npm, node, atau pustaka eksternal tambahan.
